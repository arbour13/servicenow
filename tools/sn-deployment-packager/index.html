Deploy any suite app that has a deploy.manifest.js with the Now SDK (Fluent project).

Checking apps…

Choose a saved connection to fill credentials, or New connection to type them. Connect detects the vendor prefix and whether this app is already installed.

To add a saved connection, leave New connection selected, fill in the fields, then click Save for later. Saved in this browser's local storage, including the password in plain text.

Deploy with Now SDK needs a local Node process in a second terminal (separate from your web server). Copy the command below, paste it there, and leave that window open while you Connect and Deploy.

SDK bridge: checking…

Paste in Terminal and press Enter. You should see SN Deployment Packager SDK bridge listening on http://127.0.0.1:17345 within a second. No new shell prompt after that is normal — leave the window open.
