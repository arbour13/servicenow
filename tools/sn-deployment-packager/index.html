ServiceNow Deployment Packager

Package any suite app that has a deploy.manifest.js as an Update Set XML or a Fluent project.

Checking apps…

Choose a saved connection to fill credentials, or New connection to type them. Connect detects the vendor prefix and whether this app is already installed.

To add a saved connection, leave New connection selected, fill in the fields, then click Save for later.

The zip is a full Now SDK project (package.json, now.config.json, and src/fluent/**). A README is included in the zip.
