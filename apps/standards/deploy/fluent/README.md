# GlideFast Standards Portal — ServiceNow Fluent (Now SDK) package

Generated by the packager's deploy console. This is a ServiceNow Now SDK project: the app's
widget, Angular providers, page, portal, and theme declared as metadata-as-code.

## Build & install

```bash
npm install
npm run build      # now-sdk build
npm run deploy     # now-sdk install — pushes to the instance you auth against
```

See https://servicenow.github.io/sdk/ for authenticating the SDK to your instance.

## Layout

- `src/fluent/widgets/` — the `SPWidget` and its template/css/client/server files
- `src/fluent/providers/` — each shared `SPAngularProvider` (injected by name at runtime)
- `src/fluent/page/` — the page/container/row/column/instance layout
- `src/fluent/portal/` — the portal + theme
- `src/fluent/generated/keys.ts` — stable record identity (shares sys_ids with the Update Set XML build)
