# Delivery Methodology - Fluent (Now SDK) project

Generated by the SN Deployment Packager. **These are the files the Now SDK needs to deploy this app.**
The zip is a full ServiceNow Now SDK project: Service Portal widget, Angular providers, page as metadata-as-code. Record sys_ids match the Update Set XML build, so XML and Fluent installs
update the same records.

## Prerequisites

- Node.js + npm
- Access to a ServiceNow instance that supports the Now SDK / Fluent deploy path
- The Now SDK CLI authenticated to that instance (see https://servicenow.github.io/sdk/ )

## Install & deploy

```bash
npm install
npm run build      # now-sdk build
npm run deploy     # now-sdk install - pushes to the authenticated instance
```

If the SDK is not authenticated yet, follow the SDK docs to log in before `npm run deploy`.

## Layout

- `package.json` / `now.config.json` - Now SDK project shell and scope id
- `src/fluent/widgets/` - `SPWidget` plus template/css/client/server files
- `src/fluent/providers/` - each `SPAngularProvider` (injected by name at runtime)
- `src/fluent/page/` - page / container / row / column / instance layout
- `src/fluent/generated/keys.ts` - stable record identity shared with the XML package
- `README.md` - this file
